Le parcours d’un fichier

Un traitement automatique, étape par étape.

  1. 01Dépôt

    Je place un JSON de 13 mesures dans le stockage Azure.

  2. 02Validation

    Event Grid prévient la fonction. Les fichiers invalides sont conservés avec le motif du rejet.

  3. 03Prédiction

    Une file transmet le travail à l’API, avec des reprises en cas d’échec.

  4. 04Résultat

    La prédiction est enregistrée puis affichée dans ce tableau de bord.
